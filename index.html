Laniakea open toolkit

GitHub

Unofficial tools for the Magerit Laniakea eurorack module. Everything runs in your browser; flashing and wave uploads use Web Serial (desktop Chrome or Edge).

What the custom firmware adds

CV → wavetable Y

cv_to_y

Turn any CV jack (e.g. EFFECTS) into a row / Y-axis CV and sweep both wavetable axes by modulation.

Scale quantizer

quantizer

FREQ + V/OCT snap to a scale. Pick scale and root in the SPACE menu: major, minor, pentatonics, dorian, blues and more.

8 wavetable banks

banks

Stored on the module, switched from the SPACE menu. The last bank is restored at power-up. Back up and restore all 8 banks from the editor or the command line.

Custom chord table

chords

CLUSTER chords from the Laniakea Pro set (plus sus2, sus4, add9, min9, maj6), or your own voicings.

Clearer LED menus

led_menus

Each menu gets its own tint, amounts show as bar graphs, and the ring shows the selected bank, bow/pluck, the wavetable row (gold in additive mode) and a short cue when the scale, root or chord changes. With led_dedupe, the ring is only refreshed when it changes.

Internal exciter

strum

Like Rings: with nothing in EXCITER and pluck mode, every new note opens the LPG and plucks the string. A V/OCT sequence plays plucked notes on its own; ORBITS-menu ORBITS sets the decay.

Tamed bow

bow

The string model's bow mode drowns everything in harsh, grainy noise once SHAPE brings the string in. This lowers it and keeps it even across the ORBITS knob.

Usability fixes

usability

Sane factory-reset defaults (no more silence or sub-bass), wider wavetable rows on SHAPE, and 12-semitone FREQ ranges as the manual says.

Pick any combination of these in the firmware patcher; details in the custom firmware docs.
