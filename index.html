Laniakea open toolkit

GitHub

Unofficial tools for the Magerit Laniakea eurorack module. Everything runs in your browser; flashing and wave uploads use Web Serial (desktop Chrome or Edge).

Firmware patcher →

Add features to the official firmware (wavetable banks, CV → wavetable row, scale quantizer, chord sets, menu crackle fix, clearer LEDs), build it and flash it over USB.

Wavetable editor →

Draw, morph and import waves (WAV, AKWF), manage the 8 banks and upload them to the module.
