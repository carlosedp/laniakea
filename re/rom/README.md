# ESP32 ROM / peripheral symbol files

Unmodified linker scripts from [ESP-IDF](https://github.com/espressif/esp-idf)
(`components/esp_rom/esp32/ld/` and `components/soc/esp32/ld/`, branch `master`),
© Espressif Systems, licensed under Apache-2.0 (ESP-IDF's license).

`tools/img2elf.py` reads them to name ROM functions and peripheral registers in Ghidra.
